# Flash Store
Ready-to-upload static digital store for GitHub Pages.

## Upload
Upload the contents of this folder to a GitHub repository. GitHub Pages can host it directly; no build command is required.

## Admin
Admin password: **2013** on first use.

Admin can add/edit/delete categories, change category images, add/edit/delete products, manage options/prices, manage orders, update WhatsApp/store settings, and change the admin password.

## Customer accounts
Includes browser-local Login / Sign Up, account logout, and order history.

## Important
This is a front-end/local-storage version. Accounts, passwords, products and orders are stored in each browser, so it is not suitable for real customer authentication or shared multi-device admin data. For a production store, connect Supabase/Auth/Storage and move password handling server-side.
